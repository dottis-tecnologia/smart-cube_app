## Descrições

### Descrição Curta (80 caracteres)
"Colete leituras de medidores via QR Code de forma rápida e offline."

### Descrição Completa
O Cube4Meters é o aplicativo definitivo para coleta de leituras de medidores de energia através de QR Code. Desenvolvido pela Dottis Tecnologia, oferece uma solução completa para gestores energéticos.

**Principais Funcionalidades:**
• Leitura de QR Code de medidores
• Armazenamento offline de dados
• Sincronização automática com servidor
• Interface intuitiva e moderna
• Suporte multi-idiomas
• Backup seguro de dados

**Ideal para:**
• Empresas de gestão energética
• Técnicos de campo
• Administradores de condomínios
• Gestores de consumo

Baixe agora e otimize sua coleta de dados!
