# Store Assets for App Stores

## Required Screenshots

### Google Play Store (Minimum 8 screenshots)
- **Size**: 1080x1920 pixels (or 3840x2160 for tablets)
- **Format**: PNG or JPEG
- **Recommended screens:**
  1. Login screen
  2. Dashboard/Home
  3. QR Code scanning
  4. Reading form
  5. Synchronized readings list
  6. Navigation menu
  7. Settings/profile screen
  8. Synchronization screen

### Apple App Store (Minimum 8 screenshots)
- **Size**: 1242x2688 pixels (iPhone X/11/12)
- **Format**: PNG
- **Recommended screens:** Same as Google Play

## Icons and Banners

### Google Play Store
- **App icon**: 512x512 pixels
- **Banner**: 1024x500 pixels
- **Feature Graphic**: 1024x500 pixels

### Apple App Store
- **App icon**: 1024x1024 pixels
