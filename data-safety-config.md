# Configuração Data Safety - Google Play Store

## Informações para o Formulário Data Safety

### 📊 Tipo de Coleta de Dados

#### **Dados Coletados**
- **Email**: Para autenticação e identificação do usuário
- **Nome do usuário**: Para personalização e gestão
- **ID do usuário**: Identificador único interno
- **Dados de leitura**: Valores de medidores e timestamps
- **Localização**: Opcional, para contexto da leitura
- **Imagens**: Fotos dos medidores para validação

#### **Propósito da Coleta**
- ✅ **Funcionalidades do App**: Armazenar leituras e sincronizar
- ✅ **Análise**: Melhorar qualidade do serviço
- ✅ **Segurança**: Prevenir fraudes e abusos

### 🔒 Práticas de Segurança

- **Criptografia em trânsito**: SSL/TLS
- **Criptografia em repouso**: SQLite local criptografado
- **Armazenamento seguro**: Expo Secure Store para tokens
- **Controle de acesso**: Autenticação JWT

### 📱 Uso Compartilhado

- **Não compartilhamos dados com terceiros**
- **Não vendemos dados pessoais**
- **Dados usados apenas para funcionalidades do app**

### 🌐 Local dos Dados

- **Armazenamento local**: Dispositivo do usuário (SQLite)
- **Servidor**: Brasil (https://api-smartcube.cubiiapp.com)
- **Backup**: Servidores seguros na AWS Brasil

### ⏰ Retenção de Dados

- **Dados do usuário**: Até solicitação de exclusão
- **Leituras**: 2 anos (conforme legislação)
- **Logs de sistema**: 90 dias

### 🔐 Controle do Usuário

- **Acesso**: Usuário pode visualizar todos seus dados
- **Correção**: Editar informações pessoais
- **Exclusão**: Solicitar exclusão completa da conta
- **Exportação**: Baixar todos seus dados

### 📋 Resumo para Preenchimento

**Data Collection:**
- Email addresses (Account authentication)
- User names (Personalization)
- App activity (Readings, timestamps)
- Device or other identifiers (User ID)
- Photos and videos (Meter readings)

**Security Practices:**
- Data is encrypted in transit and at rest
- Data is securely stored using industry-standard encryption

**Sharing:**
- No data sharing with third parties
- No data selling or transfer

**Data Location:**
- Brazil

**Retention:**
- User data: Until account deletion
- Reading data: 2 years
